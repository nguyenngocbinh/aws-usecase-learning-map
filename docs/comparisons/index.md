# Service comparisons

Use a decision matrix rather than declaring a universal winner. Compare workload fit, operational overhead, availability, security, performance, scaling, cost drivers, portability, and team skills.

Planned comparisons:
- S3 vs EBS vs EFS.
- AWS Glue vs EMR vs self-managed Spark.
- Athena vs Redshift vs RDS.
- RDS SQL Server vs SQL Server on EC2.
- SageMaker real-time endpoints vs serverless inference vs batch transform.
- GitHub OIDC vs CodeConnections vs static credentials.
- EventBridge Scheduler vs Step Functions vs Glue Workflows.
- AWS Backup vs service-native backups and replication.

Each comparison must cite official documentation and state assumptions/region/date where relevant.
