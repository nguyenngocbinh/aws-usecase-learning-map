# AWS Service Catalog

Danh mục dịch vụ sẽ được mở rộng theo use case. Mỗi service guide phải có đủ 10 WH questions, decision criteria, alternatives, architecture examples, pricing drivers, operational limits, and official references.

## First-wave services

| Service | Domain | Primary use |
|---|---|---|
| Amazon S3 | Storage | Object storage and data lake foundation |
| IAM | Security | Identity and access management |
| AWS Glue | Data | Serverless data integration and catalog |
| Amazon Athena | Analytics | SQL query over data in S3 |
| AWS DMS | Migration | Database migration and replication |
| Amazon RDS | Database | Managed relational database |
| Amazon SageMaker AI | ML | Model development and deployment |
| AWS Lambda | Compute | Event-driven functions |
| Amazon EventBridge | Integration | Event routing and scheduling |
| AWS Step Functions | Orchestration | Stateful workflow orchestration |
| Amazon CloudWatch | Operations | Metrics, logs, alarms |
| AWS KMS | Security | Key management and cryptographic operations |

Service pages are planned; do not treat this index as a complete service reference.
