# Amazon S3 — Hướng dẫn dịch vụ và thực hành

<small>STORAGE · OBJECT STORAGE · UC01 / UC02</small>

## 1. Amazon S3 là gì?

**Amazon Simple Storage Service (Amazon S3)** là dịch vụ **Object Storage** của AWS. Dữ liệu lưu thành object trong bucket và truy cập qua S3 API. Một object gồm nội dung dữ liệu, key và metadata.

S3 thường được dùng cho Data Lake, file ingestion, backup, logs, static assets và Machine Learning datasets.

## 2. 10 WH questions — Amazon S3

| WH | Nội dung |
|---|---|
| What | Object storage lưu object trong bucket; không phải relational database hay POSIX filesystem. |
| Why | Scalable storage cho ingestion, lake, backup, logs, artifacts và data exchange. |
| When | File/object, large datasets, archival; không thay database transaction hoặc POSIX file server mặc định. |
| Where | Bucket thuộc Region; endpoint, residency, replication và workload location ảnh hưởng thiết kế. |
| Who | IAM role/user, workload role, bucket policy principal, access point và AWS services. |
| Which | Storage class, versioning, Object Ownership, encryption, lifecycle, replication, access point. |
| How | Console, CLI, SDK, DataSync, Transfer Family hoặc Terraform. |
| How much | Storage GB-month, requests, retrieval, transfer, replication, lifecycle và optional features. |
| What if | Unauthorized access, accidental delete, overwrite, KMS issue, incomplete multipart, Region mismatch. |
| How compared | S3 object; EBS block; EFS/FSx file; DataSync/Transfer Family transfer tools. |

## 4. Secure bucket baseline

- Block Public Access bật.
- Bucket owner enforced; ACLs disabled trừ use case cần thiết.
- Versioning theo recovery requirement.
- Default encryption: SSE-S3 hoặc SSE-KMS theo governance.
- Bucket policy deny non-TLS transport.
- Least-privilege IAM; phân tách data prefixes.
- CloudTrail data events theo audit requirement.
- Lifecycle/retention phù hợp data classification.
- Replication/backup theo RPO/RTO; versioning không thay thế backup.

## 5. CLI hands-on

~~~powershell
$env:AWS_PROFILE = "aws-learning"
$env:AWS_REGION = "ap-southeast-1"
$env:BUCKET = "your-unique-learning-bucket"
aws sts get-caller-identity
aws s3api get-bucket-location --bucket $env:BUCKET
aws s3api get-public-access-block --bucket $env:BUCKET
aws s3api get-bucket-versioning --bucket $env:BUCKET
aws s3api get-bucket-encryption --bucket $env:BUCKET
aws s3 cp .\sample.csv "s3://$env:BUCKET/raw/demo/sample.csv"
aws s3api head-object --bucket $env:BUCKET --key "raw/demo/sample.csv"
~~~

## 6. Storage and transfer alternatives

| Need | Service |
|---|---|
| Object API / Data Lake | S3 |
| Linux shared filesystem | EFS |
| Windows/NFS/SMB enterprise file workloads | FSx family |
| EC2 block volume | EBS |
| Managed bulk sync on-prem ↔ AWS | DataSync |
| Managed SFTP/FTPS | Transfer Family |
| Offline large-scale transfer | Snow Family |

## 7. Cost considerations

Phân tích storage class theo access frequency, minimum storage duration, retrieval fee, object size, request count và egress. Versioning làm tăng storage vì các versions cũng chiếm dung lượng. Lifecycle transitions có thể tạo request/cost; nên test với object sample và retention thật.

## 8. Troubleshooting

| Symptom | Likely checks |
|---|---|
| AccessDenied | Identity policy, bucket policy, SCP, endpoint policy, KMS |
| NoSuchBucket | Bucket name/account/Region |
| Signature/endpoint issue | Region và credentials |
| Unexpected storage cost | Versions, incomplete multipart, replication, noncurrent objects |
| Public exposure | Account/bucket Block Public Access, policy, ACL |
| Data not queryable | Prefix/table location, format/schema, Glue Catalog |

## 9. Cleanup

Xóa đúng test prefix và object versions/delete markers trước khi xóa bucket. Kiểm tra lifecycle, replication, incomplete multipart và cost. Không dùng destructive wildcard trên account dùng chung.
