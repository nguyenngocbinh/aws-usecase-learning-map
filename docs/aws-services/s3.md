# Amazon S3 — Service Guide

<small>STORAGE · OBJECT STORAGE · UC01</small>

## What

Amazon Simple Storage Service (S3) is object storage. Data is stored as objects inside buckets and accessed through S3 APIs.

## 10 WH questions

| WH | Answer |
|---|---|
| What | Managed object storage for files, data lakes, backups, logs and application artifacts. |
| Why | High durability design, elastic scale, AWS integration, lifecycle and access controls. |
| When | File/object workloads and data lake storage; not a drop-in POSIX filesystem or relational database. |
| Where | Bucket is created in a Region. Validate data residency, service availability and cross-Region transfer implications. |
| Who | IAM principals, bucket policies, access points and AWS service principals. |
| Which | Select storage class by access pattern, retrieval tolerance, retention and minimum storage duration. |
| How | Console, S3 API, CLI, SDK/Boto3, Transfer Family, DataSync and IaC. |
| How much | Storage GB-month, request count, retrieval, transfer, replication and lifecycle transition. |
| What if | Handle policy denies, KMS permissions, versioning, incomplete multipart uploads, object lock and Region errors. |
| How compared | EBS = block; EFS/FSx = file; S3 = object. DataSync and Transfer Family solve managed transfer/protocol scenarios. |

## Core configuration choices

- Block Public Access: keep enabled unless a reviewed, explicit public hosting use case requires otherwise.
- Object Ownership: Bucket owner enforced; avoid ACLs for new designs.
- Default encryption: SSE-S3 baseline; SSE-KMS when customer-managed key controls are required.
- Versioning: enable when recovery from overwrite/delete is needed; understand version storage costs.
- Lifecycle: transition or expire objects according to retention and access policy.
- Bucket policy: deny insecure transport and express cross-account/service access deliberately.
- Access logging/audit: evaluate CloudTrail data events and their cost.

## Alternatives

| Service | Storage model | Best fit |
|---|---|---|
| S3 | Object | Data lake, files, backup, artifacts |
| EBS | Block | EC2 attached disks |
| EFS | NFS file | Shared Linux filesystem |
| FSx | Managed file systems | Windows/Lustre/ONTAP/OpenZFS workloads |
| DataSync | Managed data transfer | File/object transfer and synchronization |
| Transfer Family | Managed file transfer endpoints | SFTP/FTPS/FTP partner integration |
